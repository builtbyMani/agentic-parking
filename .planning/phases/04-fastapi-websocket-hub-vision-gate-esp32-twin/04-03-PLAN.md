  <name>Task 1: Create ESP32 firmware in hardware/esp32_lot_a/esp32_lot_a.ino</name>
  <files>hardware/esp32_lot_a/esp32_lot_a.ino</files>
  <action>
    Create `hardware/esp32_lot_a/esp32_lot_a.ino`:
    - Define pins: `SERVO_PIN = 18`, `IR_SENSOR_PIN = 19`, `STATUS_LED_PIN = 2`.
    - Setup:
      - `Serial.begin(115200);`
      - `ESP32PWM::allocateTimer(0);` or `Servo gateServo; gateServo.attach(SERVO_PIN);`
      - `pinMode(IR_SENSOR_PIN, INPUT_PULLUP);`
      - `pinMode(STATUS_LED_PIN, OUTPUT);`
      - Initial position: 0 degrees (Closed).
    - Loop:
      - Read incoming serial string: if `GATE:OPEN`, write servo angle 90, LED HIGH, set `gateOpenTime = millis()`.
      - Auto-close timer: if `gateIsOpen && (millis() - gateOpenTime >= 5000)`, write servo angle 0, LED LOW, print `GATE:CLOSED`.
      - Read IR sensor: software debounce 50ms. If transition to LOW (obstacle present), print `SLOT:A-01:OCCUPIED`. If transition to HIGH, print `SLOT:A-01:VACANT`.
  </action>
  <verify>test -f hardware/esp32_lot_a/esp32_lot_a.ino && grep -q "GATE:OPEN" hardware/esp32_lot_a/esp32_lot_a.ino</verify>
  <acceptance_criteria>

    - Enforces 5-second gate open duration
    - Emits clean serial telemetry string tokens
  </acceptance_criteria>
  <done>ESP32 firmware created in hardware/esp32_lot_a/esp32_lot_a.ino.</done>
