       - `async def broadcast(message: dict)`
    2. Lifespan context manager:
       - Runs `init_db()` on startup to ensure SQLite tables exist.
    3. CORS middleware allowing origins `["*"]` or `["http://localhost:5173", "http://localhost:3000"]`.
    4. Routes:
       - `GET /`: Health check `{"status": "online", "system": "Agentic Parking Gateway"}`
       - `GET /api/lots`: Queries SQLite `get_all_lots()`
       - `GET /api/slots`: Queries SQLite `get_all_slots()`
       - `POST /api/negotiate`: Accepts `DriverConstraints`. Runs `run_multi_lot_negotiation()` in `asyncio.create_task()`, with an `event_callback` that calls `manager.broadcast(event)`. Returns `{"status": "negotiating", "driver": driver.dict()}`.
       - `POST /api/bookings/{booking_id}/checkout`: Retrieves booking from DB or params, computes USD cents, creates order via `get_payment_provider().create_order(booking_id, total_paise)`. Returns order details.
       - `POST /api/bookings/{booking_id}/confirm`: Captures order via `get_payment_provider().capture_order(order_id)`, updates booking status to `CONFIRMED` in SQLite, generates signed QR pass via `generate_signed_qr_token()`, broadcasts `BOOKING_CONFIRMED` event, and returns QR token and booking details.
       - `POST /api/gate/verify-qr`: Accepts `{"qr_token": str}`. Calls `verify_signed_qr_token(token)`. If valid: triggers gate opening via serial bridge, broadcasts `GATE_TRIGGERED` event, returns `{"valid": True, "data": data}`. If invalid: broadcasts `GATE_REJECTED`, returns `{"valid": False, "error": error}`.
       - `GET /api/mock-paypal-approve`: Simple redirect HTML for simulated approval in mock mode.
       - `WebSocket /ws`: Accepts connection, sends initial `{event_type: "CONNECTED", data: {lots, slots}}`, listens for client pings.
