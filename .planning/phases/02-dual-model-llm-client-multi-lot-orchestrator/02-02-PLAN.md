  <action>
    Implement `backend/orchestrator.py`:
    1. Helper `emit_event(callback, event_type, negotiation_id, data)`: calls callback if provided.
    2. `negotiate_with_single_lot(negotiation_id: str, driver: DriverConstraints, lot: LotPolicy, event_callback=None) -> dict`:
       - Step 1: Opening Anchor:
         `anchor_paise = compute_opening_request_anchor(lot.base_list_paise, driver.max_budget_per_hour_paise)`
         Record opening move and emit REQUEST event.
       - Step 2: Rounds 1, 2, 3:
         - Round 1:
           Lot LLM call (sys, usr) -> `enforce_lot_guard` -> emit OFFER -> Driver LLM call -> `enforce_driver_guard` -> emit COUNTER.
         - Round 2:
           Lot LLM call -> `enforce_lot_guard` -> emit COUNTER -> Driver LLM call -> `enforce_driver_guard` -> emit COUNTER.
         - Round 3 (Best & Final):
           Lot LLM call with "THIS IS THE FINAL ROUND" -> `enforce_lot_guard` -> emit COUNTER.
         - Collect full history transcript lines so prompt builders have conversational context.
       - Returns dictionary with lot_id, final_lot_offer_paise, moves history, and qualifying status.
    3. `run_multi_lot_negotiation(driver: DriverConstraints, lots: list[LotPolicy], plate_number: str = "KA-01-MJ-2026", event_callback=None, db_path: str = DB_PATH) -> dict`:
       - Generate `negotiation_id = f"neg_{uuid.uuid4().hex[:8]}"`
       - Step 0: Distance Filter:
         `active_lots = []`
         For each lot: if `lot.distance_m > driver.max_walk_distance_m`, emit `LOT_SKIPPED` event; else append to `active_lots`.
       - Step 2: Parallel Bilateral Rounds:
         Run `await asyncio.gather(*[negotiate_with_single_lot(negotiation_id, driver, lot, event_callback) for lot in active_lots])`.
       - Step 3: Winner Evaluation:
         Filter out lots where `final_lot_offer_paise > driver.max_budget_per_hour_paise`.
         For qualifying lots, compute `score_paise = (rate * hours) + (distance_m * walk_penalty * hours)`.
         Pick lot with minimum score.
       - Step 4: Atomic Soft-Lock & Booking Creation:
         If winner:
           `slot_id = await acquire_soft_lock(winner.lot_id, 180, db_path)`
           Calculate `total_paise = winner.agreed_rate_paise * driver.hours` and `usd_cents = max(1, round(total_paise * 100 / USD_TO_INR_PAISE))`.
           Create `BookingRecord` with status `PENDING_PAYMENT`.
           Emit `ACCEPT` event for winner and `WALK_AWAY` for losers.
         Else:
           Emit `NO_DEAL` event.
       - Return full summary dict: `{negotiation_id, winner_lot_id, winning_slot_id, agreed_rate_paise, total_paise, usd_cents, booking_id, lots_results, event_log}`.
  </action>
