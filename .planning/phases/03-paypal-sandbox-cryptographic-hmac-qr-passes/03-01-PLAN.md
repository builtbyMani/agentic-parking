  <name>Task 2: Implement HMAC-SHA256 signed QR pass generator and verifier in backend/payments.py</name>
  <files>backend/payments.py</files>

  <action>
    Implement:
    1. `generate_signed_qr_token(booking_id: str, lot_id: str, slot_id: str, plate: str, valid_hours: int) -> str`:
       - Construct payload:
         `"bid": booking_id, "lot": lot_id, "slot": slot_id, "ph": hashlib.sha256(plate.strip().upper().encode()).hexdigest()[:10], "exp": int(time.time()) + (valid_hours * 3600)`
       - JSON compact bytes: `json.dumps(payload, separators=(',', ':'), sort_keys=True).encode()`
       - URL-safe base64: `b64_body = base64.urlsafe_b64encode(raw_bytes).decode().rstrip('=')`
       - HMAC signature: `sig = hmac.new(HMAC_SECRET_KEY.encode(), b64_body.encode(), hashlib.sha256).hexdigest()[:16]`
       - Return `f"{b64_body}.{sig}"`
    2. `verify_signed_qr_token(token: str) -> tuple[bool, dict | str]`:
       - Split token by `.`; reject if parts != 2.
       - Recompute expected signature: `hmac.new(HMAC_SECRET_KEY.encode(), b64_body.encode(), hashlib.sha256).hexdigest()[:16]`
       - Check `hmac.compare_digest(sig, expected_sig)`: return `(False, "Invalid HMAC signature (tampered QR)")` on mismatch.
       - Decode base64 and parse JSON.
       - Check expiration: if `int(time.time()) > data["exp"]`: return `(False, "QR pass expired")`.
       - Return `(True, data)` on success.
  </action>
