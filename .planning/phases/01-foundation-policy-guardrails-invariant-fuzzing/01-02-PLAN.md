<task type="auto">
  <name>Task 2: Implement PolicyGuard & regex prose sanitizer in backend/policy_guard.py</name>
  <files>backend/policy_guard.py</files>
  <read_first>backend/schemas.py, backend/pricing_engine.py</read_first>
  <action>
    Implement `backend/policy_guard.py`:
    1. `sanitize_message_prices(message: str, clamped_paise: int) -> str`:
       - `rupees = clamped_paise // 100`
       - Use regex `r'(?:₹|Rs\.?\s*)\d+(?:\.\d+)?'` to replace any occurrence with `f'₹{rupees}'`.
       - Append ` [Adjusted to policy limit ₹{rupees}/hr]`.
    2. `enforce_lot_guard(raw_move: AgentMoveLLM, policy: LotPolicy, hours: int, prepay: bool, round_num: int, last_lot_offer_paise: int | None, last_driver_bid_paise: int) -> tuple[int, str, str, bool, str | None]`:
       - Calculate `floor_paise = compute_effective_lot_floor_paise(policy, hours, prepay)`.
       - Set `ceiling_paise = last_lot_offer_paise if last_lot_offer_paise is not None else policy.base_list_paise`.
       - Check 1: Floor clamp (`clamped < floor_paise` -> `clamped = floor_paise`).
       - Check 2: Monotonic ceiling clamp (`clamped > ceiling_paise` -> `clamped = ceiling_paise`).
       - Check 3: Never ask less than what driver already bid (`clamped < last_driver_bid_paise and last_driver_bid_paise >= floor_paise` -> `clamped = last_driver_bid_paise`).
       - Check 4: Enforced action type: "OFFER" if round_num == 1 else "COUNTER".
       - If guard triggered: call `sanitize_message_prices(raw_move.message, clamped)`.
       - Return `(clamped, enforced_action, final_msg, guard_triggered, guard_reason)`.
    3. `enforce_driver_guard(raw_move: AgentMoveLLM, driver: DriverConstraints, round_num: int, last_driver_bid_paise: int, last_lot_offer_paise: int) -> tuple[int, str, str, bool, str | None]`:
       - `budget = driver.max_budget_per_hour_paise`.
       - Check 1: Budget ceiling clamp (`clamped > budget` -> `clamped = budget`).
       - Check 2: Monotonic floor clamp (`clamped < last_driver_bid_paise` -> `clamped = last_driver_bid_paise`).
       - Check 3: Upward-bidding guard (`clamped > last_lot_offer_paise` -> `clamped = min(budget, last_lot_offer_paise)`).
       - Check 4: Enforced action: "COUNTER".
       - If guard triggered: call `sanitize_message_prices(raw_move.message, clamped)`.
       - Return `(clamped, enforced_action, final_msg, guard_triggered, guard_reason)`.
  </action>
  <verify>python3 -c "from backend.schemas import AgentMoveLLM, LotPolicy; from backend.policy_guard import enforce_lot_guard; p = LotPolicy(lot_id='L1', name='Lot 1', distance_m=100, total_slots=10, occupied_slots=2, event_active=False, base_list_paise=4500, base_floor_paise=3500, max_prepay_discount_pct=15); move = AgentMoveLLM(action='ACCEPT', price_per_hour_paise=2000, message='Deal at ₹20/hr', reasoning='too low'); clamped, act, msg, trig, reason = enforce_lot_guard(move, p, 3, True, 1, None, 2800); assert clamped == 3000 and act == 'OFFER' and trig is True and '₹30' in msg"</verify>
